# Updated Eye Optometry Experiment Report

Results from the November 3, 2026 dataset rerun, including seven classification
tasks, Top-K feature analysis, OCT coordinate ablation, and statistical tests.

Public site: https://ClarkBigD.github.io/eye-optometry-reportnew/

The self-contained presentation is served from `site/index.html`.
Every push to `main` deploys it to GitHub Pages through GitHub Actions.
The workflow can also be started manually from the Actions tab.

To publish an updated presentation, replace `site/index.html`, commit, and push.
Publish aggregate results only; keep patient records and source workbooks out
of this repository.
